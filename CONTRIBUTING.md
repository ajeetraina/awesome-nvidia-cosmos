# Contributing to Awesome NVIDIA Cosmos

Thanks for helping keep this list useful and up to date! Contributions of all
sizes are welcome — from fixing a broken link to adding a brand-new world
foundation model release or a project built on Cosmos.

> 🤖 **Note:** This list is also maintained by an autonomous [Cosmos Auto-Curator
> agent](auto-curator-agent/cosmos-curator.yaml) that discovers new resources,
> validates links, and opens pull requests labeled `agent-bot`. Human
> contributions are always welcome alongside it.

## How to Contribute

1. **Fork** this repository.
2. **Add your resource** under the most appropriate section of `README.md`
   (Models, GitHub Projects, Tools & Deployment, Tutorials & Starter Kits,
   HuggingFace × Cosmos, Real-World Use Cases & Companies, Videos & Talks,
   Papers, Events, or Community).
3. **Keep the existing formatting** — most sections use Markdown tables with
   consistent columns (e.g. `Model | Params | Description | Links` or
   `Repo | Stars | Description`). Match the style of the surrounding rows.
4. **Verify your link works** and points to the canonical/official source
   whenever possible (official Hugging Face org, NVIDIA NIM catalog, arXiv,
   official GitHub repo, NVIDIA developer blog, etc.).
5. **Submit a pull request** with a short description of what you added and
   why it belongs in the list.

## What Belongs Here

- New Cosmos model releases with real Hugging Face / NIM links
- GitHub projects, integrations, or demos that use or build on Cosmos
  (robotics pipelines, AV data augmentation, ComfyUI nodes, fine-tunes)
- Tutorials, notebooks, or blog posts about Cosmos (Predict / Transfer / Reason)
- Tools that curate data for, deploy, evaluate, or post-train Cosmos models
- Papers that propose or evaluate Cosmos world foundation models
- Videos, podcasts, or talks featuring Cosmos
- Companies building production Physical AI with Cosmos (with public references)
- Events relevant to Cosmos and the NVIDIA Physical AI ecosystem

## What Doesn't Belong Here

- Unofficial or unverified forks/mirrors with no added value
- Empty repositories, dead links, or resources that no longer exist
- Content unrelated to NVIDIA Cosmos or the broader Physical AI ecosystem
- The unrelated **Cosmos SDK** blockchain framework (`cosmos/cosmos-sdk`) or
  other name collisions
- Duplicate entries already covered elsewhere in the list

## Style Guide

- Use `**Bold**` for model/resource names.
- Keep descriptions concise — one line per entry.
- For GitHub projects, note whether the repo is **official NVIDIA** or
  **community**, and include an approximate star count where helpful.
- Sort new rows within a table in a sensible order (e.g. newest first, or by
  stars / generation) to match the surrounding entries.
- Prefer official links over third-party aggregators.

## Reporting Issues

If you find a broken link, outdated information, or duplicate entry, please
[open an issue](../../issues) or submit a pull request with the fix.
